## 1. ASMR削除について ── 分析

### 結論：同意します。理由は3つあります。

#### ① 参考動画の87万いいねは「買う人」の数字ではありません

@kankula667 は個人のレザークラフト作家です。あの動画を保存した人が次にやることは、**革を買って自分で作ること**です。5万円のバッグを買うことではありません。
第1版でも同じ指摘をしています（「87万いいねは作り方を見たい人の数字。買う人の数字ではありません」）。永尾さんの判断が正しいです。

#### ② 「かぶってる」は、そのとおりでした。ただし判定基準を1つ足させてください

送っていただいた4本のうち、**ASMR（@kankula667）とメイキング（delvaux）は、同じ画（工房の手元）を、同じ相手（新規）に、同じ場所（公式インスタのショート）で出す**ものでした。**素材・相手・置き場所の3つが全部同じ。**これはかぶりです。

一方で、**工房で撮った映像を複数の動画で使い回すこと自体は、かぶりではありません。**
1本目「ブランドの価値」・7本目「コーポレート」・8本目「OEM工房案内」は、**同じ工房の素材を使いますが、尺も比率も置き場所も相手も違います。**

| | 尺・比率 | 置き場所 | 相手 |
|---|---|---|---|
| 1本目 ブランドの価値 | 60秒・縦9:16 | 公式インスタ／EC Promotion | 新規のお客様 |
| 7本目 コーポレート | 2分・16:9 | B supplyホームページ／永尾さんのインスタ／YouTube | メディア関係者 |
| 8本目 OEM工房案内 | 2分20秒・16:9・無音 | 営業／展示会／OEMページ | 調達担当 |

**「かぶり」は素材ではなく、置き場所と相手で判定してください。**工房の撮影を1日で済ませて3本作るのは、無駄ではなく効率です。

#### ③ 露出先5つのうち2つで、音が出ません

これが今回いちばん強い理由です。

| 露出先 | 音は出るか |
|---|---|
| 草ヶ谷さんのインスタ | 出る |
| ブルックリン公式インスタ | 出る |
| 永尾さんのインスタ | 出る |
| **B supplyホームページ** | **出ない**（自動再生・ミュート） |
| **ブルックリンEC Promotionタブ** | **出ない**（自動再生・ミュート） |

**ASMRは「音が主役」の形式です。**5つの露出先のうち2つで、価値がゼロになります。
今回の露出先の決まり方から見ても、**音に依存しない作り（テロップと画だけで成立する）に統一するのが正解**です。

### ただし、工程の撮影そのものはやめないでください

| | |
|---|---|
| **なぜ要るか** | ①コーポレート No.4「製造」、②OEM工房案内 No.4〜8、1本目「ブランドの価値」で必ず使います |
| **やめるのは形式だけ** | 「音だけで20秒もたせる」をやめます。素材（裁断・縫製・コバ磨き）はそのまま使います |
| **スケジュールは短くなります** | DAY2（向島工房）は27カット中21カットが③でした。**削除で6カットになり、半日 → 2時間程度に短縮**されます |
| **廃止する資料** | `docs/04_工程ショート_スタートキット.md` ／ `docs/05_絵コンテ改訂とテロップ集.md` ／ `pdf/03_改訂版_絵コンテとテロップ集.pdf` ── アーカイブ扱いにします |

### 「手の、理由。」について

**撤回します。説明不足でした。**
7本それぞれに「なぜ機械でなく手でやるのか」を分担させる仕掛けでしたが、**タイトルを見ただけで意味が伝わらない時点で、コピーとして失敗**です。
第2版では、**詩的な言い回しを一切使いません。**テロップは**数字と、見れば分かる言葉**だけにします（例：「1160g」「A4とPCが同時に入る」「全工程の40%」）。

## 2. 露出先5つ × 8本 ── 今回いちばん大事なところ

### 5つの露出先の性格

### ここから出る技術的な結論（3つ）

1. **8本すべて、縦9:16をマスターにして撮ってください。**
   公式インスタは後々 TikTok・YouTubeショートへ展開します。16:9で撮ると縦に切り出せません（逆は切り出せます）。
2. **16:9が必要なのは7本目・8本目の2本だけです。**
   この2本は16:9で撮り、縦版を切り出します（B supplyホームページ＋永尾さんのインスタの両方に載るため）。
3. **8本すべて、音を切っても意味が通るように作ってください。**
   露出先5つのうち2つが無音再生です。**テロップだけで成立するかを、書き出す前に必ずミュートで確認**してください。
