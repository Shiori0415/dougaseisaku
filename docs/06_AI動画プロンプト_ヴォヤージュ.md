# AI動画プロンプト ── Voyage（ヴォヤージュ）を持って旅に出る　服三パターン版

参考動画：いただいた画面録画二本（innovator SWEDEN のリール。一本目＝並木道 → 水辺 → バスターミナル、二本目＝空港ロビー → 待合 → ロゴ。合わせて約三十一秒・横16:9）

参考動画は **服とスーツケースの色が四つ**（紺スーツ×シルバー／白ワンピース×青／青シャツ×黄／ピンクコート×ラベンダー）。
これを **一人・鞄一つ・服三パターン** にまとめる。**鞄は最初から最後まで同じ。服だけが替わる。**

## 手順

1. **ルック画像を三枚つくる**（ステップ1）。顔と鞄は三枚とも同じ、服だけ替える。
2. **カットごとに、その服のルック画像を起点に動画にする**（ステップ2）。一カット五秒で生成し、編集で詰める。
3. **服が替わるカット（C3・C5・C10）は、前の服と後の服で二本に分けて生成し、編集でワイプの位置でつなぐ。**
   一本の生成の中で服を替えさせると、顔と鞄が崩れる。

## 生成の設定

- 比率：**16:9**（参考動画と同じ）。Instagramのリールに縦で出すなら、9:16で別に生成する（横を切り抜くと鞄が切れる）
- 一カット：**五秒で生成して、編集で秒数に詰める**
- 動き：人物は「歩く」「立ち止まる」「鞄を置く」だけにする。手の細かい動き（開ける・中を探る）は崩れやすいので入れない
- 顔：その服のルック画像を毎回参照画像として渡す（画像1だけを渡すと、カットごとに顔が変わる）
- 服が替わるつなぎ（C3・C5・C10→C11）：**前後の二本で、ふさぐもの（車・木の幹・人影）の位置と動く向きをそろえる**
