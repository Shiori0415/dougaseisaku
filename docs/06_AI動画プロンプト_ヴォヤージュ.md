# AI動画プロンプト ── Voyage（ヴォヤージュ）を持って旅に出る

参考動画：いただいた画面録画二本（innovator SWEDEN のリール。一本目＝並木道 → 水辺 → バスターミナル、二本目＝空港ロビー → 待合 → ロゴ。合わせて約三十一秒・横16:9）

## 参照画像の割り当て

| 参照 | 使うところ | 使わないところ |
|---|---|---|
| 画像1（人物） | 顔立ち・肌の色・髪の色と長さ | ドレス・ティアラ・たすき・背景のパネル |
| 画像2（鞄） | 形・革の質感・色・ベルト・金具・大きさ | ロゴの文字・背景 |
| 画像3（服） | ジャケット・ニット・ネックレス・デニム・パンプス | マネキン・部屋・カーペット |

---

## 手順（この順で回すと、顔と鞄がカットごとにぶれない）

1. **ルック画像を一枚つくる**（下の「ステップ1」）。画像1・2・3を同時に読ませて、全身・正面の一枚を固める。
2. **その一枚を起点に、カットごとに動画にする**（「ステップ2」）。一カット五秒で生成し、編集で詰める。
3. **編集でつなぐ**。つなぎは参考動画と同じ「手前を横切るものでワイプ」。

## ステップ2　カットごとの動画プロンプト

共通で頭に付ける一文：
```
ステップ1の画像と同じ人物・同じ服・同じ鞄。顔と鞄の形を変えない。
シネマティックな広告映像、自然光、24fps、浅い被写界深度、望遠レンズの圧縮感、横16:9。
```

### 一本目　並木道 → 水辺 → バスターミナル（約十五秒）

| # | 秒 | プロンプト |
|---|---|---|
| C1 | 0–3.5 | 初夏の晴れた並木道。円すい形の木が両側に並ぶ。**バストショット**。女性が右肩に鞄を掛け、ハンドルに手を添えて、笑顔で前を見ながらこちらへ歩いてくる。**カメラは後ろ向きに下がりながら同じ距離で追う**。背景は大きくボケる。画面の中央上に、あとでロゴを入れる余白を空けておく。 |
| C2 | 3.5–5 | 水辺の遊歩道。石の車止めが等間隔に並び、奥に水面と植え込み。**引き・カメラ固定**。女性が画面の奥から手前へ、鞄を肩に掛けて歩いてくる。 |
| C3 | 5–5.5 | 同じ遊歩道。**手前を紺色の車が左から右へ速く横切り、画面をふさぐ**（次のカットへのワイプ）。 |

| C5 | 8.5–12 | 公園の植え込みと大きな木の幹。**太い幹を手前にナメて、カメラが横へ移動**。女性が幹の向こうを歩き、**幹が画面をふさいだところで切る**（ワイプ）。 |
| C6 | 12–15 | 屋根付きのバスターミナル。緑色の番線表示、奥に赤い路線バス。**正面から、女性が鞄を肩に掛けて歩いてくる**。ミディアムから引きへ、カメラはゆっくり下がる。笑顔で少し横を見る。 |

## 生成の設定

- 比率：**16:9**（参考動画と同じ）。Instagramのリールに縦で出すなら、9:16で別に生成する（横を切り抜くと鞄が切れる）
- 一カット：**五秒で生成して、編集で秒数に詰める**
- 動き：人物は「歩く」「立ち止まる」「鞄を置く」だけにする。手の細かい動き（開ける・中を探る）は崩れやすいので入れない
- 顔：ステップ1のルック画像を毎回参照画像として渡す（画像1だけを渡すと、カットごとに顔が変わる）
