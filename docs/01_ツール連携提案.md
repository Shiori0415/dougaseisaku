# 動画制作の連携ツール提案（現在連携済み以外）

対象：BROOKLYN MUSEUM ／ 向島工房 動画企画 ①〜⑩
前提：現在すでに連携済み＝Adobe、Canva、Dropbox、Gmail、Googleカレンダー、Googleドライブ、HeyGen HyperFrames、Miro、Slack、monday.com、GitHub。
以下はそれ以外で、今回の10企画を回すのに実際に効くものだけに絞っています。

---

## まず入れる3つ（これだけで回り始めます）

| 順 | ツール | 何が変わるか | 費用目安 |
|---|---|---|---|
| 1 | **Frame.io（Camera to Cloud）** | 撮影中の素材がその場でクラウドに上がる。向島の撮影日に永尾社長・佐藤さんが立ち会えなくても、その日のうちにOK/NGが返る。秒数を指定したコメントが打てるので「1:28の検品カット、もう1テイク」が文字で残る | Adobe契約に付帯（無料枠あり） |
| 2 | **DaVinci Resolve** | 編集・カラー・音が1本。③工程ASMRは音が主役なので、Fairlight（音声パート）が同じソフトに入っているのが効く。マクロ撮影は革の色が転びやすく、カラー補正が必須 | 無料（Studio版 ¥47,980 買い切り） |
| 3 | **Epidemic Sound** | BGMと効果音の商用ライセンス。YouTube・Instagram広告・展示会ループ再生・商談用タブレットまで、企画書に出てくる配信媒体を1契約で全部カバーする。ここを曖昧にすると広告出稿時に止まる | 月 約¥2,600〜 |

## 工程別の一覧

### 企画・設計
| ツール | 用途 | この企画での効き所 |
|---|---|---|
| **StudioBinder** | 絵コンテ・ショットリスト・香盤表・コールシートが1本 | 撮影日が7日に分かれる。日別のコールシート（誰が何時にどこへ）を自動生成できる |
| **Boords** | 絵コンテ専用。コマを並べて尺どおりに再生（アニマティック）できる | ①2分・②2分20秒は、撮る前に尺が合うか検証しないと現場で破綻する。AIでコマ絵も出る |
| **Milanote** | ビジュアルリファレンス集め | 「参考写真」欄が空のカットが多い。ここを埋める置き場 |

※ Miro（連携済み）で構成と絵コンテを持ち、StudioBinderで現場運用、が現実的な分担です。

### 撮影
| ツール | 用途 | この企画での効き所 |
|---|---|---|
| **PhotoPills / Sun Surveyor** | 日照シミュレーション | ①の「刻印に光が差す」、②の工房外観、巻末⑭「工房の朝」は光の入射時刻で成否が決まる。向島工房の窓光が床を切る時刻を事前に確定できる |
| **Shot Lister** | 現場でショットリストを消化管理 | 全企画で約90カット。撮り漏らしが出ると再ロケになる |
| **Blackmagic Camera（iOS無料）** | iPhoneでLog収録 | ③ASMR8本・⑧色合わせ6本は真俯瞰の物撮り。専用機材を出さずに済む |
| **Insta360 / GoPro** | 小型アクションカメラ | 巻末②「うまれるひ」（商品視点の一人称）に必須 |

### 編集
| ツール | 用途 | この企画での効き所 |
|---|---|---|
| **Descript** | 文字起こしベース編集。文章を消すと映像が消える | 永尾社長30分＋佐藤さん30分の収録から、使う各10秒を探す作業。⑤購入者インタビュー、巻末⑩⑪の単独版展開もここが最速 |
| **CapCut** | 縦型の量産 | ③8本・⑧6本・⑨15秒縦型。同じ型の繰り返しなのでテンプレート化が効く |
| **iZotope RX** | ノイズ除去 | ASMRは工房のエアコン音・機械のうなりが致命傷になる。ここだけは専用ツールが要る |
| **Topaz Video AI** | 解像度・フレームレート補正 | 手縫いや裁断のハイスピード撮影が足りなかった場合の救済 |

### 生成AI（実撮影の代替ではなく、合意形成用）
| ツール | 用途 | この企画での効き所 |
|---|---|---|
| **Google Veo / Runway Gen-4 / Kling** | 絵コンテを動く映像に（プリビズ） | 「こう撮ります」を社長・職人に見せてから撮影日を組む。撮影当日の手戻りが消える |
| **Midjourney** | 絵コンテのコマ絵生成 | 現状「参考写真：要撮影」の欄を、撮る前に絵で埋める |
| **ElevenLabs** | ナレーション音声 | 巻末②「うまれるひ」の商品一人称ナレーション、②OEM版の多言語化 |

### 配信・計測（KPIに直結）
| ツール | 用途 | この企画での効き所 |
|---|---|---|
| **Wistia** または **Vimeo** | 商品ページ埋め込み＋動画単位の計測 | ④のKPI「再生完了率60%」は、YouTube埋め込みでは品番別に測れない。Wistiaなら何秒で離脱したかがヒートマップで出る。「A4を入れるカットで落ちている」が分かる |
| **Metricool** または **Later** | Instagram・YouTubeの予約投稿と計測 | KPIの「保存率（保存数÷リーチ）1%」「プロフィール遷移率2%」は手集計では続かない。自動集計に載せる |
| **Googleビジネスプロフィール** | Googleマップ・検索の店舗枠に動画掲載 | ⑥店舗案内のKPI「経路案内リクエスト月50」の計測元そのもの。無料 |
| **Meta広告マネージャ／YouTube Studio** | 広告出稿と維持率 | ①のKPI「平均視聴維持率50%以上」の計測元 |

## 連携のつなぎ方（推奨フロー）

```
Miro（構成・絵コンテ・ショットリスト）
  └→ StudioBinder（香盤表・コールシート）→ 撮影当日
        └→ Frame.io / Camera to Cloud（素材が即共有・秒数コメントで承認）
              └→ Dropbox（マスター保管：連携済み）
                    └→ DaVinci Resolve（編集・カラー・音）
                          ├ Descript（インタビュー尺の切り出し）
                          ├ Epidemic Sound（BGM・効果音）
                          └ iZotope RX（ASMRのノイズ除去）
                                └→ 書き出し
                                      ├ Wistia → Shopify商品ページ（④⑤⑦）
                                      ├ Metricool → Instagram / YouTube（③⑧⑨）
                                      ├ Googleビジネスプロフィール（⑥）
                                      └ Googleドライブ（商談・展示会用：連携済み）
  進捗は monday.com（連携済み）、連絡は Slack（連携済み）
```

## 入れないほうがいいもの
- **Notion**：monday.com が既にあります。管理台帳を二重に持つと必ず片方が腐ります。
- **Premiere Pro を新規契約**：Adobe契約があるなら使えますが、③ASMRの音づくりを考えるとResolve1本のほうが早い。両方を並行運用しないこと。
- **AI動画生成での本編制作**：①〜⑩はすべて「実在の工房・実在の職人」が価値です。生成映像を本編に混ぜると、②OEM向けの「設備・工程の水準を伝える」という目的そのものが崩れます。プリビズ止まりにしてください。
