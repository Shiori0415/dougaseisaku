## 1. なぜオチが弱かったのか ── コピーライターの診断

> 「オチが弱いのは、フレーズが**説明**になっているからです。
> 『形が、生まれる。』『一本の、線になる。』は、画面で起きていることを言葉にしただけ。
> **映像と言葉が同じことを言うと、両方が弱くなります。**
> 言葉の仕事は、**映像が語れないことを1つだけ足す**こと。
> いちばん効くのは、**視聴者が知らない事実**を置くことです。」

### テロップの原則 4つ

| # | 原則 | 理由 |
|---|---|---|
| 1 | **説明しない。事実を1つだけ置く** | 映像と重複した瞬間、両方が弱くなる |
| 2 | **視聴者が知らないことを言う** | 知っていることを言われると、そこで飽きる。逆に知らない事実は「保存」される |
| 3 | **体言止め・助詞止め。「です・ます」を使わない** | 敬体は距離を作る。工芸の文体ではない |
| 4 | **商品を褒めない。手つきと道具を褒める** | 商品を褒めた瞬間に広告になる |

### 使用禁止語

**「丁寧」「こだわり」「職人技」「本物」「想い」「一つひとつ」**
── 聞いた瞬間に脳が処理をやめる言葉です。使うのは**動詞と名詞と数字**だけ。
（ご提案の「一枚、一枚丁寧に。」もここに該当するため、別案に置き換えました）

### 数字は漢数字で

「40%」より「**四割**」。「1mm」より「**一ミリ**」。工芸の文体に合い、画面上でも締まります。

## 2. テロップ 全7本（本命＋代案）

各本に「**一般の人が知らない、その工程の本当の理由**」を1つずつ割り当てました。
これで7本全部が「なぜ手でやるのか」に答えることになり、総集編がなくても主題が立ちます。

### 1本目　金型裁断
> **知られていない事実**：型は同じでも、革のどこに置くかで製品の寿命が変わる。革は部位ごとに繊維の詰まりが違う。この作業を業界では「型入れ」と呼ぶ。

| | フレーズ |
|---|---|
| **本命** | **「型を置く前に、革を読む。」** |
| 代案A | 「一枚の革に、いい場所は限られている。」 |
| 代案B | 「同じ型で、違う場所を抜く。」 |

### 2本目　革包丁
> **知られていない事実**：革包丁は使うたびに研ぐ。研ぐたびに刃は減る。長く使った包丁は、目に見えて短くなっている。

| | フレーズ |
|---|---|
| **本命** | **「長く使った道具が、長く使えるものを作る。」** |
| 代案A | 「減っていく道具で、減らないものを作る。」 |
| 代案B | 「切れない刃は、革を切らずに潰す。」 |
| 締め（包丁だけのカットに重ねる） | 「道具は、減った。」 |

### 3本目　糊付け
> **知られていない事実**：革小物は1枚ではなく、複数枚を貼り合わせて作る。**貼り合わせないと断面（コバ）が作れず、磨けない。** 糊は接着ではなく、縫うまでの仮止め。

| | フレーズ |
|---|---|
| **本命** | **「貼らないと、磨けない。」** |
| 代案A | 「糊は、縫うまでの仮の約束。」 |
| 代案B | 「二枚にするのは、断面を作るため。」 |

### 4本目　ミシン縫製（＋糸切り・コテ焼き）
> **知られていない事実**：縫い終わりの糸は結ばない。**切って、焼いて留める。**

| | フレーズ |
|---|---|
| **本命** | **「終わりは、結ばない。焼く。」** |
| 代案A | 「最後のひと針は、火で閉じる。」 |
| 代案B | 「結び目は、いつか解ける。」 |

### 5本目　手縫い（＋糸切り・コテ焼き）
> **知られていない事実**：手縫い（サドルステッチ）は2本の糸が交差しているので、**1目切れても隣がほどけない。** ミシンは1本の糸なので、1箇所切れると連鎖してほどける。**これが手縫いの唯一の合理性。**

| | フレーズ |
|---|---|
| **本命** | **「一目切れても、隣はほどけない。」** |
| 代案A | 「ミシンは一本の糸。手は、二本。」 |
| 代案B | 「ほどけない縫い方が、ひとつだけある。」 |

### 6本目　目止め
> **知られていない事実**：革の裏（床面）は毛羽立っている。目止めをすると毛羽が寝て、ホコリを吸わなくなる＝汚れにくくなる。買った人が見ない面。

| | フレーズ |
|---|---|
| **本命** | **「裏は、見せないために整える。」** |
| 代案A | 「毛羽が寝ると、汚れなくなる。」 |

### 7本目　コバ磨き　★1本目に投稿
> **知られていない事実**：コバは、持つたびに**指が最初に触れる場所**。誰も見ないが、いちばん触っている。
> ご指摘のとおり「この40%が、価格の理由です。」は不採用にしました。価格の話をした瞬間に、広告になります。

| | フレーズ |
|---|---|
| **本命（オチ）** | **「誰も見ない一ミリに、四割の時間を。」** |
| 代案A | 「見えない場所ほど、長く触れている。」 |
| 代案B | 「褒められない場所に、いちばん時間をかける。」 |
| **冒頭テロップ**（この本だけ・音が鳴って0.5秒後・2秒で消す） | 「一つの製品の、四割の時間は、この一ミリに使われます。」 |

### シリーズ名

現行「手で、つくる意味。」は、総集編があってこそ成立する説明的な名前でした。総集編を外したので、**より短い名前を推します。**

| | 名前 |
|---|---|
| **推し** | **「手の、理由。」** ── 7本すべてが「なぜ手でやるのか」に答える構造と完全に一致します |
| 代案 | 「手でやる理由。」／「向島の、手つき。」 |
| 現行 | 「手で、つくる意味。」（このままでも成立します） |

全7本の最後に、この名前を0.5秒だけ入れてください。

## 3. ご質問への回答

### Q1. 1本目のラスト、1枚だけ？ それとも模様みたいに並べる？

**模様で並べてください。ただし、最後の0.5秒で手が1枚だけ取る。** 両方使うのが正解です。

1. **冒頭が「金型がアート的に並んでいる」**ので、最後も並びで返すと**円環が閉じます。** 始まりと終わりが同じ形をしていると、20秒でも「作品」になります。
2. **縦型9:16で1点だけだと画面が余ります。** 並べると画面が埋まり、スクロールを止める力が強くなります。
3. ただし**並べただけだと「工場」に見えて、手仕事の話になりません。** 最後に手が1枚を取ることで「無数の中から選ばれた1枚」になり、テロップ「型を置く前に、革を読む。」と接続します。

**並べ方は不規則に。** きれいに整列させるとカタログの写真になります。角度を少しずつ変えて、重なりも作ってください。

### Q2. 「マクロで正体不明 → 引いていく」入りは、どれに合う？

**3本目 糊付けです。**

1. 7本のうち**3本目がいちばん弱い**（尺が短く、動きが地味で、音も小さい）。てこ入れが要るのはここです。
2. ご指定の「**糊が上から落ちてくる**」は、超マクロだと**完全に正体不明**になります（透明な液体が糸を引いて落ちるだけ）。引くとヘラと革が現れる。**この落差が7本の中でいちばん大きい。**
3. 次点は6本目 目止め（毛羽立った床面のマクロも正体不明）。ただし糊のほうが「動き」があるぶん強いので、**3本目に本命、6本目に軽めの同じ手を使う**構成にしました。
