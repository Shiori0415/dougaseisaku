対象＝新規（まだ知らない人）　／　EC Promotionタブ・公式Instagram
製造工程のリアリティを伝える一本。作業音をそのまま入れる（バック音声あり）。刃が革に入る音、槌の音、糸が締まる音、コバを磨く摩擦音。音があるだけで、本当にここで作っていることが伝わる。ナレーションは入れない。 アングルは真俯瞰と横の二つだけ。音はカメラのマイクでは録れないので、スマホを手元三十センチに置いて別録りする。
参考動画：Link（@kankula667）　＋　Link（コバ塗り・477万再生）
2本。@kankula667「レザークラフト作ってみた #asmr」＝約60秒。緑のカッターマットの上で、革包丁で裁つ → 定規で直線 → ヘリを落とす → 目打ちで印 → 菱目打ちで穴 → ボール盤とカシメ → 刻印 → 手縫い → 仕上げ剤 → コバ磨き → 完成品を置くまで、工程を省略せずに順番どおり見せている。コバ塗り（477万再生）＝約19秒、赤い財布の断面に道具の先を当てて塗っていく寄り一本。
S1 裁つ
0-5秒
超マクロ。刃が革に入る瞬間。何を見ているか分からない距離。「スッ」と抜ける一音だけ。BGMは鳴らさない
刃が進み、革の繊維が開いていく（同じ画角のまま）
切り終わり。断面がまだ生成りのまま残っている
S2 形を出す
5-11秒
真俯瞰。金属定規を当てて直線を一気に引く
角を回して切る（横）
ヘリを落とす。断面の角が丸くなる（超マクロ）
S3 穴を開ける
11-17秒
目打ちで縫う位置に印をつける
菱目打ちを槌で打つ。同じ音が三回続く（横）
等間隔に並んだ穴だけが画面に残る
S4 金具をつける
17-22秒
ボール盤で金具用の穴をあける
カシメを打つ。金属が革に沈む一音
刻印を押す。斜めから光を当てて、窪みに影を作る
S5 縫う
22-28秒
針が革を抜ける（寄り）
二本の糸が交差して締まる（超マクロ）
縫い目に沿って仕上げる。手の動きだけを見せる
S6 コバ塗り
28-34秒
塗り始め。道具の先が断面に触れる（超マクロ）
この一本の見せ場。塗った側と塗っていない側が同じ画面に入る。長回し・カットを割らない
塗り終わり。同じ画角のまま断面の色が変わりきっている
S7 磨く
34-38秒
ヘラで仕上げ剤を薄く伸ばす
超マクロ。コバを磨く。摩擦音
磨き終わった断面に、光が一本だけ走る
S8 使われる場所へ
38-40秒
作業机ではなく、使われている場所に置く → テロップ → ロゴ
