① 　案 A

ジェラートを持って歩く

Pattern A ／ One Scoop, Three Outfits
30秒 ／ 10ショット　／　服 三パターン
対象＝新規・リピーター　／　全媒体
参考動画＝Link（innovator SWEDEN）　／　撮影地＝代官山（公道のみ）
企 画手に持つものは変えない。服だけを変える。ジェラートを受け取ってから、食べ終わって段差に座るまでを一続きにする。そのあいだに服と鞄が二回変わる。

持ち物が同じだから、服が変わったことだけが目に入る。四色を並べる元の作りより、街の温度が画に残る。ジェラートは溶けるので、一色につき一つ、買い直す。

道順。ジェラート屋の前　→　八幡通りの並木　→　猿楽町の坂　→　段差に座る。歩く向きは一度も変えない。

撮るのは公道だけ。旧山手通り・八幡通り・猿楽町の坂・ジェラート屋の前。私有地（ヒルサイドテラスの敷地・代官山T-SITE・ログロード）と区立公園には入らない。手持ちで撮り、三脚は歩道に置かない。だから撮影の許可は要らない。

着替えは車の中。駐車場を一か所に決めて、そこから半径三百メートルで三色とも撮る。
こ の 1 本 で 言 う こ と持つものが変わらないから、服が変わったことだけが見える。

同じ道を、違う私で。
THE SAME ROUTE, A DIFFERENT ME.
こ の 案 の 強 み と 弱 み強み。街の生活感が入る。ジェラートが手にあるので、立ち姿が硬くならない。撮り直しが利く ── 同じ道を三回歩くだけ。
弱み。ジェラートが溶ける。一色ぶん十五分以内で撮り切る。雨だと成立しない（予備日に振り替える）。

① 　案 B

同じ画角で三回、立ち止まる

Pattern B ／ One Frame, Three Outfits
30秒 ／ 8ショット　／　服 三パターン
対象＝新規・リピーター　／　全媒体
参考動画＝Link（innovator SWEDEN）　／　撮影地＝代官山（公道のみ）
企 画カメラを一度も動かさない。同じ場所・同じ画角で、「歩いてくる　→　画の真ん中で立ち止まる　→　フレームの外へ出る」を三回撮る。変わるのは服と鞄だけ。

切り替わりは、手前を人が横切った一コマ。代官山は人通りがあるので、待てば必ず来る。通行人の顔は写さない（前ボケで抜ける位置に立つ）。

足元にテープで印を付ける。三回とも同じ場所に立ってもらう。カメラは胸の高さ。手持ちだが、背中を壁につけて固定する。

場所は旧山手通りの歩道（ヒルサイドテラスの白い壁と列柱を背に、敷地には入らない）。

撮るのは公道だけ。旧山手通り・八幡通り・猿楽町の坂・ジェラート屋の前。私有地（ヒルサイドテラスの敷地・代官山T-SITE・ログロード）と区立公園には入らない。手持ちで撮り、三脚は歩道に置かない。だから撮影の許可は要らない。

こ の 1 本 で 言 う こ と同じ場所に立っているのに、服が変わるだけで別の一日に見える。

① 　案 C

進んで、巻き戻る

Pattern C ／ Forward, Then Rewind
30秒 ／ 10ショット　／　服 三パターン
対象＝新規・リピーター　／　全媒体
参考動画＝Link（innovator SWEDEN）　／　撮影地＝代官山（公道のみ）
企 画元の企画を、三色に詰めたもの。前半は進み、後半は巻き戻る。一色目　→　二色目　→　三色目 と進みきったあと、人が通るたびに一つ前の服に戻る（三色目　→　二色目　→　一色目）。

戻るカットは、進んだときと同じ画角・同じ立ち位置で撮る。同じ場所に戻ってくるから「巻き戻った」と分かる。画角を変えると、着替えただけに見える。

切り替わりの合図。進むとき＝車が通り過ぎる／街路樹の裏を通る。戻るとき＝人が通る。

場所は旧山手通りの一本で撮り切る。進む三つの立ち位置を先に決め、戻りでも同じ三か所を使う。一か所につき二回ずつ通る。

撮るのは公道だけ。旧山手通り・八幡通り・猿楽町の坂・ジェラート屋の前。私有地（ヒルサイドテラスの敷地・代官山T-SITE・ログロード）と区立公園には入らない。手持ちで撮り、三脚は歩道に置かない。だから撮影の許可は要らない。

着替えは車の中。駐車場を一か所に決めて、そこから半径三百メートルで三色とも撮る。
こ の 1 本 で 言 う こ と服が変われば、合う革の色も変わる。同じ革・同じ色で、財布から鞄まで揃う。
