## 2026年9月の変更点

1. **「漉き」の工程を削除**（実際にはない工程のため）。工程ASMRは 8本 → 7本。※ 企画書「② OEM工房案内」の対応技法一覧にも「漉き」が入っているので、そちらも要修正です
2. **⑧ 色合わせショートを全面書き換え** ──「定番色でもいいけど、この色にすると華やかになるよね！」という切り替えの動画に。実際の色のHEXも記載
3. **⑪「この道、20年。」を新規追加** ── 佐藤さん出演・60秒。新規撮影は4シーンのみ
4. **絵コンテを「1シーン ＝ 1行、右に3つのアングル案」の形に作り直し**、参考写真をつけました
