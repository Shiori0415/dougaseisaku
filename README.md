## 2026年9月 第3版（8本ラインナップ）

永尾社長のご指摘（露出先5つの確定／ASMR不要／ターゲット3分類の整理）を反映しました。

### 1. ③ 工程ASMRショート（7本）を削除

- 削除の根拠は `docs/06` 1章。**同意しています。**理由は3つ ──(1) 参考動画の87万いいねは「作り方を見たい人」の数字で、買う人の数字ではない (2) ASMRとメイキングは素材・相手・置き場所の3つが同じで、実際にかぶっていた (3) **露出先5つのうち2つ（B supplyホームページ／EC Promotionタブ）が無音再生**で、音が主役の形式は価値がゼロになる
- **シリーズ名「手の、理由。」は撤回。**タイトルだけで意味が伝わらない時点でコピーとして失敗。以後、詩的な言い回しは使わず、テロップは数字と見れば分かる言葉だけにする
- **ただし工程の撮影はやめない。**①コーポレート／②OEM工房案内／新1本目「ブランドの価値」で必ず使う。DAY2は27カット → 6カットに短縮
- `docs/04`／`docs/05`／`pdf/03` はアーカイブ扱い

### 2. 露出先5つを確定（今回いちばん大事）

草ヶ谷さんのインスタ ／ ブルックリン公式インスタ（後々 YouTube・X・TikTok）／ 永尾さんのインスタ ／ B supply ホームページ ／ ブルックリンEC Promotionタブ（新設）

技術的な結論は3つ。**(1) 8本すべて縦9:16をマスターにする**（16:9で撮ると縦に切り出せない）／**(2) 16:9が必要なのは⑦⑧の2本だけ**／**(3) 8本すべて音を切っても意味が通るように作る**（5つのうち2つが無音再生）
