# 議事録 → 個人todo 自動転記

Geminiが作る会議メモの「次のステップ」から自分宛のタスクを拾い、
管理スプレッドシートの「個人todo」ブロックに自動で書き込む。

## なぜApps Scriptなのか

Claude側からスプレッドシートのセルを書き換える手段が無い。
接続できるGoogle連携は Drive（読み取り中心）と Calendar のみで、
Sheetsの書き込みコネクタは提供されていない。
そのため、シート自身にスクリプトを持たせて動かす形にした。
無料・サーバー不要・権限は本人のGoogleアカウントの範囲内で完結する。

## 設置手順（初回のみ・5分）

1. 対象スプレッドシートを開く
2. メニュー **拡張機能 → Apps Script**
3. 既存のコードを消して `todo_sync.gs` の中身を全部貼り付け、保存
4. 上部の関数選択で **setupTrigger** を選び、実行
   - 初回のみGoogleの権限承認画面が出る
   - 「このアプリは確認されていません」→ 詳細 → 安全でないページに移動、で進む
     （自分が書いたスクリプトなので公開審査を通していないだけ）
5. 完了。以後は毎朝8時に自動で走る

手動で走らせたいときは、シートを開き直すと出る
メニュー **TODO同期 → 議事録から取り込む** を押す。

## 動き

- 過去14日以内に更新された、本文に「次のステップ」を含むGoogleドキュメントをDriveから探す
- その中の `[宮下詩織] ○○` という行を抜き出す
- シートの「個人todo」ブロックにある空行へ書き込む（空行が尽きたら行を挿入）
- 各セルのメモに出典ドキュメント名とURLと取込日時を残す
- 一度取り込んだドキュメントと、既にシートにあるタスク名は二重登録しない

## 書き込む内容

| 列 | 入る値 |
|---|---|
| C | `・` |
| D | タスク本文（議事録そのまま） |
| E | 優先度 `中`（空のときだけ） |
| F | 実行日 |
| G | **空のまま**（議事録に期日が無いため推測しない） |
| H | `未着手` |

終了日は自動で埋めない。議事録に書かれていない情報を作らないため。

## 設定を変える

`todo_sync.gs` 冒頭の `CONFIG` を編集する。

| 項目 | 意味 |
|---|---|
| `SHEET_GID` | 転記先シートのgid（URLの `#gid=` の数字） |
| `OWNER_NAME` | 拾う担当者名。議事録の表記と完全一致させる |
| `SECTION_LABEL` | 書き込み先の見出し（B列） |
| `LOOKBACK_DAYS` | 何日前までの議事録を見るか |
| `COL` | 各列の位置。シート構成を変えたらここを直す |

担当者を増やすなら `OWNER_NAME` を変えたコピーを別関数として足す。

## 想定される詰まりどころ

- **「個人todo」の見出しが見つからないと落ちる** … B列にその文字列がある前提。
  見出しの位置や表記を変えたら `SECTION_LABEL` と `COL.SECTION` を合わせる
- **列がずれる** … `CONFIG.COL` の数字を実際の列に合わせる（1=A, 2=B …）
- **同じタスクが再登録される** … 議事録側の文言が変わると別タスク扱いになる。
  `TODO同期 → 取り込み履歴をリセット` は全ドキュメントを読み直すので、
  重複が出た場合はシート側で消す
- **議事録が拾われない** … 本文に「次のステップ」が無い、
  または14日より古い。`DOC_KEYWORD` と `LOOKBACK_DAYS` を調整する
